# 実Coinbaseへの接続確認

## 目的と範囲

`CoinbaseLiveConnectionIT`は、実際のCoinbase Exchange公開APIにBTC-USDのLevel 1注文板を1回要求し、Client → 外部応答DTOと受信時刻 → Mapper → MarketObservationの流れを確認する。APIキーは不要。DB保存・定期実行・画面は対象外で、MySQLやViteの起動も不要。

通常の自動テストは模擬HTTPと固定データを使う。この実接続確認もJUnitで自動判定するが、外部サービスへ依存するため普段のテストやCIには含めず、必要なときに明示実行する。

## PowerShellから実行

プロジェクトの`backend`フォルダーをカレントディレクトリにして実行する。

```powershell
.\mvnw.cmd "-Dtest=CoinbaseLiveConnectionIT" "-Dcoinbase.live-test=true" test
```

- `-Dtest`：実行するテストクラスを指定する。
- `-Dcoinbase.live-test=true`：実際の外部接続を許可するテスト専用スイッチ。
- `test`：Mavenのテスト工程を実行する。

通常の`.\mvnw.cmd test`では、末尾が`IT`のこのクラスはSurefireの既定対象に含まれない。クラスを指定しても許可スイッチがなければJUnitがスキップする。依存ライブラリの取得が必要な初回と実API接続にはネットワークが必要。

## IntelliJから実行

1. テストクラスの実行構成を作成し、「実行構成の編集」を開く。
2. VMオプション（必要なら「オプションの変更」から表示）へ`-Dcoinbase.live-test=true`を設定する。プログラム引数には入れない。
3. そのテスト構成を実行する。許可設定なしで緑の実行ボタンを押すとスキップになる。

## 判定と限界

成功時は1件成功となり、観測時刻とBid/Ask・数量を出力する。価格の具体値は固定せず、通貨ペア・正の価格/数量・Bid≦Ask・受信時刻の引継ぎ・sourceAtがnullであることを確認する。

接続3秒・読取り待ち5秒という既存設定の初期値を使い、アプリ独自の再試行は行わない。これらは総所要時間の保証ではない。ネットワーク障害・HTTPエラー・API仕様変更やオークション等で観測が不採用になる場合も、この確認は失敗となる。理由を調べ、コードの不具合と外部環境の問題を区別する。成功はその時点の正常経路の疎通を示すもので、異常系の網羅や常時接続を保証しない。
