# 定期実行・起動時回収の動作確認

更新：2026-11-09。機能Dの操作手順。個別テストケースの仕様はテストソースに集約する。

## 今回から変わる起動時の動作

通常のバックエンド起動では、残存RUNNINGの回収後にCoinbaseの公開APIを1回取得し、その処理終了から60秒ごとに収集する。GETで画面から参照する処理は収集を開始しない。Vueの業務画面は次工程で作成する。

自動テストは収集Service/HTTP境界のモックや収集無効化を使い、実Coinbaseへ自動接続しない。以下の手動操作は実Coinbaseへ接続し、開発DBに履歴と採用した価格を追加する。

## IntelliJでの確認

1. Docker Desktopと開発用Compose MySQLを起動する。既存のバックエンドを止め、同じDBへ接続するバックエンドは1プロセスだけにする。
2. `CryptoMarketMonitorApplication`の実行構成から通常起動する。追加のVM引数は不要。`coinbase.live-test`はJUnitの実接続試験専用であり、本処理の有効化設定ではない。
3. ログで`Recovered interrupted collection runs: 数字`を確認する。回収失敗なら起動が失敗し、自動収集は開始しない。
4. PowerShellから下記の2 APIを参照する。初回結果が返るまで少し待ち、履歴のSUCCESS/FAILED/SKIPPEDと対応する最新価格を確認する。

```powershell
Invoke-RestMethod 'http://127.0.0.1:8080/api/v1/collection-runs?limit=5' | ConvertTo-Json -Depth 10
Invoke-RestMethod 'http://127.0.0.1:8080/api/v1/quotes/latest' | ConvertTo-Json -Depth 10
```

5. 60秒＋前回処理時間を経た後、履歴を再参照する。新しい実行が増えれば周期制御を確認できる。同価格でも採用した取得ごとに保存する。失敗時に最新価格が古いままでも、新しい失敗履歴を確認する。
6. 正常な終了要求を送ると新規予約を止め、処理中なら最大30秒待つ。IntelliJのStopを重ねて強制終了すると、終了処理を通らないことがある。強制終了そのものや処理の必ずの完了は保証しない。

DBを停止したまま起動すると、回収を含む初期化が失敗する。意図せず既存行を書き換える手動SQLや、開発データの削除はこの確認手順に含めない。

## 自動収集を止めて参照だけ行う

IntelliJのアプリ実行構成の環境変数へ`COLLECTION_ENABLED=false`を指定して再起動する。またはVMオプションへ`-Dmarket-monitor.collection.enabled=false`を追加する。**RUNNINGの回収は実行する**。既定値trueに戻すには追加設定を外して再起動する。

| 環境変数 | 既定値 | 用途 |
|---|---|---|
| COLLECTION_ENABLED | true | 自動収集の登録有無 |
| COLLECTION_FIXED_DELAY | 60s | 前回終了から次回開始まで |
| COLLECTION_SHUTDOWN_WAIT | 30s | 終了待機枠 |

本番相当の周期は60秒のままとし、手動確認のために短い周期で実APIを連打しない。自動試験の短い周期はモック収集だけを対象とする。

## 自動試験

backendで次を実行する。

```powershell
.\mvnw.cmd test
.\mvnw.cmd -Pmysql-it verify
```

通常試験は200件。DB試験は51件（B21＋C25＋D5）。後者はDocker Desktopが必要で、開発用DBやViteは使用しない。通常試験にDの実Spring終了・ThreadPoolTaskScheduler試験も含む。試験区分・モック境界・前提と期待結果は各ソース冒頭と観点IDを参照する。

代表的な読み順：`CollectionStartupRunner.run` → `CollectionPersistenceService.recoverInterruptedRuns` → `CollectionRunRepository.recoverInterruptedRuns` → `CollectionScheduler.start/collectSafely/stop`。既存の`CollectionService.collectBtcUsd`がA/Bを接続する。
